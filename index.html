🔖 Edge 收藏夹

导入方式：
方式 A（推荐）：Edge 地址栏输入 edge://favorites → 打开收藏夹管理 → 右上角 ⋯ → 导出收藏夹，保存 HTML 文件后选择导入。
方式 B：直接选择本地收藏文件（无扩展名）：C:\Users\你的用户名\AppData\Local\Microsoft\Edge\User Data\Default\Bookmarks
互通：点「导出 Edge(HTML)」生成的 HTML 文件，可在 Edge edge://favorites → ⋯ → 导入收藏夹 批量导入，所有分类文件夹将直接出现在 Edge 收藏夹栏中。
说明：浏览器安全策略不允许网页自动读取本地文件，首次需手动选择一次文件；重复导入会自动按网址去重，并给已有书签补齐缺失分类。导入时收藏夹的子文件夹会自动转换为分类（根文件夹直属书签为未分类）。
